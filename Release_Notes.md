# Release Notes for <mark>stm32cubemx2_lps22df_datalog_i3c_entdaa</mark>

# Purpose

This example demonstrates how to use the LPS22DF part driver with STM32CubeMX2 on I3C bus with ENTDAA.

### First release

Initial release of the lps22df_datalog_i3c_entdaa example for STM32CubeMX2.

## Known limitations

No limitation raised for this example.

## Dependencies

Configuration and code generation features require STM32CubeMX2 >= 1.1.0.
